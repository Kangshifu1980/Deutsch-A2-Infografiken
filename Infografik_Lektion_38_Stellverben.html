🟩 Grammatik kompakt
stehen / liegen beschreiben eine Position: Wo? → Dativ. stellen / legen beschreiben eine Veränderung: Wohin? → Akkusativ.
stehen / liegen mô tả vị trí; stellen / legen mô tả sự thay đổi vị trí.

stehen ↔ stellen

Der Stuhl steht in der Küche.
Ich stelle den Stuhl in die Küche.
đứng ↔ đặt đứng

liegen ↔ legen

Das Buch liegt auf dem Sofa.
Ich lege das Buch auf den Tisch.
nằm ↔ đặt nằm

hängen

Wo? Das Bild hängt an der Wand.
Wohin? Ich hänge es an die Wand.
Động từ giống nhau; câu hỏi và cách cho biết ý nghĩa.

ins / ans

in das → ins
an das → ans
Dạng rút gọn thường dùng.

🟧 Gemeinsam einrichten

Vorschläge machen

Sollen wir …? Stell … ans Fenster. Legen wir … ins Wohnzimmer.

Position prüfen

Passt … hier? Hier ist noch Platz. Wo hängt … jetzt?
🟥 Achtung — typische Fehler
✗ Ich stehe den Stuhl in die Küche.
✓ Ich stelle den Stuhl in die Küche.
stehen = Position; stellen = eine Person verändert die Position.
✗ Ich liege das Buch auf den Tisch.
✓ Ich lege das Buch auf den Tisch.
liegen = Position; legen = Handlung.
✗ ans die Wand
✓ an die Wand
ans = an das. Feminin bleibt: an die Wand.
🟪 Beispiele aus der Lektion
Der Sessel steht mitten im Wohnzimmer. → Stell ihn ans Fenster.Ghế bành đang ở giữa phòng khách. → Đặt nó cạnh cửa sổ.
Der Teppich liegt im Flur. → Wir legen ihn ins Wohnzimmer.Thảm đang ở hành lang. → Chúng ta đặt nó vào phòng khách.
Das Bild hängt an der Wand. → Ich hänge es an die Wand über dem Sofa.Bức tranh đang treo trên tường. → Tôi treo nó lên tường phía trên ghế sofa.
Die Lampe steht auf dem Tisch. → Ich stelle sie auf die Kommode.Đèn đang trên bàn. → Tôi đặt nó lên tủ ngăn kéo.
